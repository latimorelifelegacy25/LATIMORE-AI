## Overview — Why This Drip Exists

A single follow-up message rarely earns trust with a family making a protection decision. Most prospects need several respectful, low-pressure touches before they're ready to book a conversation — and the touches that work best teach something useful, prove local credibility, and make the next step easy rather than urgent. This system replaces one-off follow-up with a structured 30-day nurture sequence so every lead — regardless of source — receives a consistent, trust-building journey from first contact to booked consultation, without requiring manual follow-up on every single lead.

## Six-Stage Framework

| Stage | Purpose |
|---|---|
| **Welcome** | Confirm receipt, set expectations, remove ambiguity about what happens next |
| **Education** | Teach one simple, useful framework for estimating coverage needs |
| **Social proof** | Establish local/community credibility (PAHS, Coal Region ties) |
| **Soft ask** | Invite a no-pressure protection review |
| **Urgency nudge** | Explain the real cost of waiting, without fear tactics |
| **Re-engagement** | Add fresh value and reopen the conversation for leads who've gone quiet |

## Automation Rules

1. **Trigger:** A new lead is created and its source is captured.
2. **On entry, immediately:**
   - Apply the source + sequence + stage tags from the Trigger Sources table.
   - Send the Day 0 email and text.
   - Schedule the remaining touches (Day 2, 5, 10, 17, 30).
3. **Conditional branches:**
   - **If the lead books:** stop the sequence, move pipeline stage to `Booked`, create a reminder task for the confirmed appointment.
   - **If the lead replies:** pause automation, move pipeline stage to `Engaged`, flag for manual follow-up.
   - **If the lead opts out:** stop all messaging immediately, tag `Opted Out`, suppress from all future sequences.
4. **No-response rule:** If there has been no reply and no booking by Day 10, create a manual task for Jackson Latimore with a short call-script outline (reference the lead's original source and interest).
5. **Re-engagement rule:** At Day 30, if there has been no engagement, tag the lead `Cold` and move to a long-term nurture list rather than continuing active outreach.

**Pseudo-flow:**
```
Lead comes in → source captured → tags applied → Day 0 send
     → scheduled drip (Day 2, 5, 10, 17, 30)
     → [reply] → pause drip → Engaged → manual follow-up
     → [booked] → stop drip → Booked → reminder task
     → [opt-out] → stop drip → Opted Out → suppressed
     → [no response by Day 10] → manual task created
     → [no engagement by Day 30] → Cold → long-term nurture list
```

## KPIs to Track

| KPI | Target | How to Measure | Weekly Action if Below Target |
|---|---|---|---|
| Email open rate | 35%+ | CRM email analytics | Test a new subject line angle |
| Click-through rate | 3%–8% | CRM link tracking | Simplify or reposition the CTA |
| Reply rate | 5%+ | CRM inbox / reply tracking | Make the ask more personal or specific |
| Booking conversion | 10%–20% | Bookings ÷ sequence entries | Shorten the path from email to booking link |
| Sequence completion | 80%+ | Leads reaching Day 30 without opt-out | Check for a drop-off point and revise that touch |
| Cold lead revival | 5%–10% | Cold-tagged leads re-engaged after Day 30 | Send a distinct value-add re-engagement message |

**Weekly review checklist (10 minutes):**
1. Pull open/click/reply rates for the week.
2. Note any KPI below target.
3. Identify the single touch (Day 0–30) with the steepest drop-off.
4. Make one adjustment to that touch (subject line, CTA, or timing).
5. Confirm no leads are stuck without a tag or pipeline stage.

**Two A/B tests to run:**
- Subject lines: direct/practical ("The 3-question coverage check") vs. curiosity-driven ("What waiting actually costs").
- CTA phrasing: "Book a quick call" vs. "Reply with a question" — measure which drives more replies vs. bookings.
